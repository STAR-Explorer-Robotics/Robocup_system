# super_odometry ROS 2 package

This package contains the estimator implementation, sensor adapters, configuration and launch descriptions.

Start with the [module README](../README.md) for the source map and dependencies. The companion message definitions are in [super_odometry_msgs](../super_odometry_msgs/package.xml).

Prior-map localization is controlled by the mapping-node parameters and the selected launch file. Prior maps and recorded bags are external inputs; no development-machine dataset or calibration session is bundled.

The original package metadata is preserved. Its license declaration differs from the upstream root README declaration recorded in the [license inventory](../../../LICENSES.md).
